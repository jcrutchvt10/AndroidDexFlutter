# RewriteDEX Desktop Wallpaper Magisk Module

This module redirects Android's secondary-display fallback wallpaper to the
separately installed RewriteDEX agent. It does not replace the selected
wallpaper on display 0 and does not install the agent as a system app.

Install `RewriteDEX-Desktop-Wallpaper-2.2.0.zip` from Magisk and reboot. To
roll back, disable or remove `RewriteDEX Desktop Wallpaper` in Magisk and
reboot. Android will return to SystemUI's stock fallback wallpaper.
